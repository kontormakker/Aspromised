# AsPromised 1.9 RC

**Sammenlign det, du blev lovet, med det dokumenterede resultat.**

AsPromised er et local-first værktøj til forbrugersager. Læg tilbud, annonce, ordrebekræftelse eller anden dokumentation for det lovede på venstre side. Læg faktura, leveringsbesked, foto eller andet resultatmateriale på højre side. AsPromised bygger en sporbar sammenligning og markerer dokumenterede forskelle.

Det er bevidst **ikke** en juridisk domsmaskine. Manglende bevis behandles ikke som bevis for, at et løfte blev brudt, og AsPromised fastslår ikke ansvar, svig eller ret til refundering/erstatning.

## Produktgrænse

> **LOVET → RESULTAT → SPORBAR FORSKEL**

AsPromised sammenligner brugerens eget materiale. Det er ikke juridisk rådgivning eller et juridisk afgørelsessystem.
