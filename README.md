# AsPromised

**Fik du det, du blev lovet?**

AsPromised sammenligner dokumenteret **løfte-evidens** med dokumenteret **resultat-evidens** og viser sporbare forskelle i fx pris, levering, inkluderede dele, garanti, returvilkår og andre konkrete løfter.

➡️ **Brug AsPromised:** https://kontormakker.github.io/Aspromised/

## Hvad det er

Eksempler på situationer:

- håndværkerfaktura højere end tilbuddet
- værkstedsregning dyrere end aftalt
- forkert pris i forhold til ordrebekræftelsen
- levering senere end lovet
- manglende varer eller inkluderede dele
- hotel eller abonnement ikke som beskrevet

AsPromised er **local-first**. Dokumenter og sagsdata behandles i browseren; den gratis offentlige version har ingen konto, backend eller analytics.

AsPromised organiserer og sammenligner den evidens, brugeren selv leverer. Det afgør ikke juridisk ansvar, beviser ikke hændelser uden for materialet og antager ikke, at manglende dokumentation betyder et brudt løfte.

## English

**AsPromised — Did you get what you were promised?**

A local-first consumer evidence comparison tool that compares promise evidence (quotes, listings, contracts, order confirmations or messages) with outcome evidence (invoices, delivery records, received-item evidence or later messages) and produces a traceable promise-vs-outcome delta.

Relevant areas: consumer rights, evidence comparison, document analysis, dispute preparation, local-first software and privacy-preserving browser tools.
